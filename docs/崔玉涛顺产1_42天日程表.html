崔玉涛 · 顺产 1-42 天日程表

崔玉涛推荐顺产坐月子1-42天日程表

注意事项+饮食营养

✓新手爸妈必须知道的事（建议打印）

第1天：好好休息

重点事项 初看到宝宝很兴奋，但今天请控制少说话，多睡觉，休息为主
饮食推荐 藕粉、蒸蛋羹、小米粥、玉米粥、三鲜面、木瓜牛奶露
  1. 产后尽可能第一时间给宝宝喂初乳
  2. 产后2小时，留意出血情况；产后3-6小时，及时排尿
  3. 顺产后6-8小时，需下地走动，促进恶露排出
  4. 前3天恶露多，每天用流动的温水冲洗，并擦拭干净

第2天：产后多翻身

重点事项 给新生儿喂奶，按需喂养
饮食推荐 什锦面、虾仁蛋炒饭、海带排骨汤、豆浆、苹果
  1. 产后第一周，不喝下奶汤，以防堵奶。
  2. 母乳亲喂保证至少2小时一次，充分刺激泌乳。
  3. 产后牙齿敏感，产后3天用漱口水清洁，每天2-3次
  4. 少碰冷水，不要吹冷风

第3天：准备回家啦

重点事项 出院时戴好帽子，穿好外套和袜子，不要吹到冷风
饮食推荐 西红柿炒鸡蛋、木耳炒黄花菜、芹菜炒牛肉木瓜牛奶
  1. 顺产3天出院，剖腹产7天出院
  2. 用一次性内裤和一次性产褥垫，不用清洗，避免尴尬
  3. 开始穿哺乳内衣，方便哺乳
  4. 出院前带宝宝做完检查，领取《出生证明》《疫苗本》

第4天：在家多躺卧

重点事项 少抱宝宝，少弯腰，换尿不湿和洗澡等让家属或月嫂做
饮食推荐 黑芝麻糊、清蒸鲈鱼、肉片炒蘑菇、红枣银耳汤
  1. 喂奶以侧躺为主，抱喂的话借助哺乳枕省力
  2. 出现乳头皲裂，可涂羊脂膏缓解，注意调整哺乳姿势
  3. 产后易出汗，多换衣服，以防受凉
  4. 房间需通风，每天3次，每次半小时，不要捂月子

第5天：适应宝宝的生活节奏

重点事项 宝宝睡了，妈妈也尽可能闭眼休息
饮食推荐 红豆燕麦粥、莫笋炒肉丝、山药木耳、香菇炒鸡肉、南瓜粥
  1. 用碘伏擦拭宝宝的脐带，每天2次，直到脱落
  2. 如果堵奶了，让宝宝下巴对着有硬块的方向吸
  3. 用生姜、艾草熬水，睡前泡脚，有利于恢复

第6天：可以洗头了

重点事项 洗头时躺着，让老公帮着洗，洗完低档热风吹
饮食推荐 香葱花卷、水煮虾、番茄菠菜汤、玉米虾饺
  1. 产后钙需求量大，要继续补充钙
  2. 少看手机和平板，过度用眼会导致视力下降
  3. 少食多餐，餐后加点心，如：红枣、黑芝麻糊、酸奶等

第7天：注意皮肤保湿

重点事项 皮肤保湿补水，避开精油成分，不要使用美白、除皱型产品
饮食推荐 花菜炒肉、鹌鹑蛋、核桃仁炖乌鸡、燕麦南瓜粥
  1. 使用面膜，可用温水泡一下再敷
  2. 不要长时间坐着或躺着，多在室内走动
  3. 产后第7天，可以洗澡了，但不要坐浴

第8天：进入过渡期

重点事项 身体恢复的同时，可以学习照顾宝宝
饮食推荐 红豆粥、菠菜鱼片汤、虾仁馄饨、红枣银耳汤
  1. 制定时间表，分配好日常事务时间，如喂奶、换尿不湿
  2. 月子里尽量减少亲朋好友的探访
  3. 检查侧切或撕裂伤口恢复情况，伤口恢复好了，可以开始做凯格尔运动

第9天：了解宝宝的护理误区

重点事项 学习新生儿护理知识，科学照顾宝宝
饮食推荐 胡萝卜肉包、阿胶红枣羹、红烧鱼、虾皮小油菜、苹果
  1. 出生后2-3天出现黄疸，7-14天自然消退
  2. 少量吐奶、奶秃、睡觉四肢抖动等，这些是正常情况
  3. 不要给宝宝戴手套，不要过度摇晃或高抛宝宝
  4. 新生儿6个月内不用睡枕头，不要睡软床

第10-12天：重视宝宝的心理需求

重点事项 宝宝只是还不会说出他的需求，不是没有需求
饮食推荐 煮鸡蛋、竹笋莲子鸡、清炒娃娃菜、黄豆炖猪蹄、黄瓜汁
  1. 多与宝宝对视，给他看色彩鲜艳、会转动的玩具
  2. 多与宝宝说话，让宝宝有安全感
  3. 多给宝宝温柔抚触，促进宝宝的发育
  4. 多逗宝宝笑，宝宝一般在出生10天左右学会被逗笑

第13-14天：母乳不足，学会追奶

重点事项 母乳喂养的宝妈，不用焦虑母乳不足，有时是休息不足导致的，多休息即可
饮食推荐 煮玉米、炒鸡蛋、腰果虾仁、花生排骨粥、冰糖雪梨汤
  1. 建立充足奶量，最好的办法是：模仿新生儿吃奶频率，24小时内挤8次奶，白天间隔2.5小时挤1次，晚上5小时1次
  2. 可以手动挤奶，或者是用吸奶器
  3. 挤奶时，宝宝的味道、哭声、照片都有助于更快挤出
  4. 挤奶不应该痛，正确的挤奶是挤压乳晕
  5. 身体越放松，挤奶越容易。如果一直没法挤出，可用温热毛巾敷一会

第15-18天：快速恢复期

重点事项 宝妈身体状态好多了，也基本适应每天照顾宝宝的生活作息了，可以开始调整宝宝的睡眠
饮食推荐 鸡蛋饼、红烧土豆鸡块、鲫鱼豆腐汤、莴笋炒虾仁
  1. 可以做一些轻微的家务，如：整理衣物，有助于恢复
  2. 让宝宝区分昼夜，最有效的方法就是：让宝宝明白白天是有趣的，白天有人陪他玩，晚上是安静的，没有人陪玩
  3. 建立相对固定的睡眠时间和哄睡方式
  4. 从第15天开始，每天给宝宝补充400国际单位的维D

第19-23天：宝宝进入猛长期

重点事项 宝宝所需养分比较多，频繁喝奶
饮食推荐 冬瓜炒豆皮、无花果瘦肉汤、丝瓜汤、红糖姜茶
  1. 躺着喂奶，这样他吃奶的时候你也能休息
  2. 少吃多餐，每3小时喂一次，白天多喂奶，晚上少喂奶，临睡前喂一次
  3. 不要过多使用安抚奶嘴，可能会造成乳头混淆
  4. 可能有胀奶疼痛问题，让宝宝多吸，或手动挤奶

第24-28天：预防月子病

重点事项 重点留意身体不适，进行针对性的恢复（记得在28天内办好新生儿医保，报销宝宝的检查费）
饮食推荐 炒猪腰、清蒸多宝鱼、黄花菜汤、花生红豆汤、花生枸杞露
  1. 耻骨痛：一般几个月~1年会缓解，多进行产后骨盆锻炼，有利于促进恢复
  2. 手腕酸痛：把手泡在稍热一点的水里，手腕会舒服很多
  3. 产后腰疼：用热水袋热敷，平时不要久坐久站或负重
  4. 尿失禁：从产后第5周开始锻炼骨盆底肌肉
  5. 产后脱发：因为激素的变化，产后2~3周脱发尤为严重，不必惊慌，这属于生理性脱发，慢慢会恢复回来的

第29-34天：美丽妈妈行动

重点事项 宝妈可以注重白身各方面的恢复了
饮食推荐 白灼芥蓝、板栗烧鸡、蘑菇青菜、清蒸鲈鱼、蒸紫薯
  1. 刷牙：选择合适的牙刷，早晚用温水漱口
  2. 头发：用指腹按摩头皮，清洗后适当用护发素
  3. 皮肤：补充睡眠，多吃含维C、维E的蔬果
  4. 脸部：日常脸部清洁和保湿，每周2-3次的脸部按摩
  5. 身材：选择轻度的有氧运动，必要时做产后康复
  6. 恶露：一般4-6周排完，如未排干净，及时就医

第35-41天：宝宝的首次外出

重点事项 宝妈身体基本恢复，宝宝更强壮，可外出
饮食推荐 蒜苗炒肉、红豆意米粥、玉米鸡丁、菌菇肉丝煲、鲫鱼汤
  1. 首次外出，可以在小区附近转一转
  2. 天气晴朗且无风时，可以去空气新鲜的公园或郊外
  3. 根据外出时长，需要准备的东西不同，如：衣物、小毯子、尿不湿、湿纸巾、驱蚊药、宝宝安抚玩具等
  4. 外出要提前考虑到：在什么地方给宝宝换尿布、喂奶

第42天：产后体检

重点事项 分娩后的第一次全面体检，包括宝妈和宝宝
饮食推荐 奶黄包、炒竹笋、清蒸排骨、冬瓜肉丸汤、绿豆莲子汤
  1. 预约体检医院，备齐体检资料（产检报告、出院小结等）
  2. 除了宝宝做检查，妈妈也要做体检，建议老公或家人陪同前去
  3. 宝宝体检项目，包括：头尾/身长/胸围/体重测量、婴儿智力发育评价和喂养指导
  4. 宝妈检查项目，包括：询问妊娠、分娩和坐月子的情况，检查产后恢复状况
