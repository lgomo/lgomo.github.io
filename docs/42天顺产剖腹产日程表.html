42 天顺产剖腹产日程表

42天坐月子日程表

第1天：好好休息

重点事项 开奶：2小时喂一次母乳，没奶也让宝宝吸
饮食推荐 顺产：南瓜小米粥、蔬菜肉末粥、肉丝面、陈皮瘦肉汤
剖腹产：陈皮炒米水、陈皮碎肉粥、西红柿鸡蛋面（排气后）
  1. 顺产后30分钟内，剖腹产2小时内，给宝宝喂初乳，早接触、早开奶
  2. 产后2小时至第二天，留意出血情况
  3. 顺产后6-8小时，需下地走动，促进恶露排出
  4. 剖腹产后6小时内去枕头平躺，6小时后枕枕头，多翻身，防止粘连
  5. 顺产后可以吃流食/半流食，剖腹产要排气后才能吃
  6. 前三天奶水少，提前备好小罐奶粉，用勺子喂奶，避免rt混淆
  7. 剖腹产如果疼痛难忍，可以在医生指导下用止痛药

第2天：多翻身、下床走动

重点事项 新生儿喂奶按需喂养，母乳不够时泡奶粉
饮食推荐 顺产：清蒸鲈鱼、彩椒肉丝、淮山排骨汤、香菇青菜、米饭
剖腹产：香菇肉丝面、青菜瘦肉粥、陈皮瘦肉汤、蒸蛋羹
  1. 产后第一周，不喝下奶汤，不吃油腻食物，避免堵奶
  2. 新生儿喂奶先亲喂30分钟（两边各15分钟），吃不饱再喂配方奶，每次20-30ml，间隔2-3小时，按需哺乳
  3. 有侧切的妈妈准备空心坐垫，能舒缓伤口不适
  4. 剖腹产妈妈术后24小时下床走动，拔尿管后4小时内要排尿
  5. 可以刷牙，用温水
  6. 每3-4小时换一次卫生巾，每天睡前温水清洗私处

第3天：出现生理性胀奶

重点事项 开始生理性胀奶，持续一周左右，提前备好吸奶器
饮食推荐 顺产：黄花菜木耳炒蛋、蒸豆腐虾仁、香芋排骨、木瓜牛奶
剖腹产：清蒸鱼腩、黄花菜炒肉片、清炒西蓝花、蔬菜粥
  1. 生理性胀奶，让宝宝多吸吮，如果宝宝不吸，吸奶器2-3小时吸一次，可以用包菜、土豆片、冷敷贴敷胸部消肿
  2. 副乳肿胀：可一边喂奶一边轻揉，力度要轻
  3. 顺产可以温水淋浴了，洗澡时间10分钟内
  4. 产褥汗多，及时更换衣服
  5. 多喝温水，吃些蔬菜和水果，便秘严重可借助开塞露
  6. 不要过早抱孩子，身体未恢复，多躺多睡

第4天：出院回家

重点事项 宝宝提前办理出院手续
饮食推荐 早餐：小米滑鸡粥、水晶虾饺、红枣红豆汁
中餐：高纤地瓜饭、焖鸡翅中、清炒菠菜、黄芪红枣瘦肉汤
晚餐：五谷饭、话梅排骨、清炒芥兰、紫菜蛋花汤
  1. 顺产3天出院，剖腹产3-5天出院，路上注意保暖，不要吹冷风
  2. 出院前将新生儿出生证明、宝宝疫苗本办好
  3. 剖腹产回家后可洗头（躺着洗）、擦澡，等一周左右伤口愈合再淋浴
  4. 不要捂月子，可开空调，24-26℃比较舒适，房间每天通风2次
  5. 剖腹产妈妈可以正常饮食了，多吃维C和优质蛋白，有利于伤口恢复
  6. 哺乳妈妈每天三餐两点，哺乳耗气血，饮食要均衡

第5天：分工照顾妈妈和宝宝

重点事项 宝爸要做好家人的分工，宝妈回家要多休息
饮食推荐 早餐：三鲜饺子、蔬菜饼、藜麦南瓜小米粥
中餐：紫薯饭、玉米蒸肉饼、清炒红薯叶、菠菜枸杞猪肚汤
晚餐：小米白米饭、荔浦芋头蒸排骨、虾仁滑蛋、炒圆包菜
  1. 宝宝洗澡后，用碘伏给脐带消毒，保持干燥，一般两周左右脱落
  2. 宝妈不碰凉水、不弯腰、不提重物，除了喂奶少抱宝宝，容易腰痛
  3. 血性恶露减少，变成淡红色的浆性恶露，量减少，持续10天左右
  4. 保持心情愉悦和良好睡眠，预防产后抑郁
  5. 此时宝宝奶量大约是60ml/次，一天喂养8次（母乳宝宝按需喂养）
  6. 记得给宝宝办理户口本、新生儿保险

第6天：适应宝宝的作息时间

重点事项 宝宝睡觉的时候妈妈要休息，闭目养神也可以
饮食推荐 早餐：芝士蛋三明治、灌汤包、红糖黑芝麻饮
中餐：糙米饭、白灼基围虾、蒜蓉娃娃菜、菌菇瘦肉汤
晚餐：燕麦饭、豌豆炒鸡丁、清炒油菜、萝卜丝煎鸡蛋汤
  1. 产后容易贫血缺钙，继续补铁、补钙，有利于身体恢复
  2. 不要长时间躺着看手机，尤其是半夜，视力下降真的很快
  3. 母乳妈妈保证8-10h睡眠，每天喝水2000ml以上，有助于乳汁分泌
  4. 不要攒奶，多吃多产奶。半夜容易堵奶，一定要吸出来
  5. 喂奶前可热敷，促进乳汁分泌，喂奶后冷敷，缓解肿胀
  6. 不要一直躺着，多在室内走动

第7天：了解宝宝护理误区

重点事项 学习新生儿护理知识，科学照顾宝宝
饮食推荐 早餐：馄饨、白灼秋葵、冰糖雪梨炖木瓜
中餐：红豆饭、茶树菇蒸牛肉、芦笋炒鱼片、虾滑冬瓜汤
晚餐：藜麦饭、栗子焖排骨、肉沫烩老豆腐、当归红枣鸡汤
  1. 宝宝比大人多半件，摸颈部温暖，手脚微凉但不冰，就是穿衣合适
  2. 纯母乳喂养不需要额外喂水，奶粉宝宝两餐之间喂10ml左右水
  3. 换尿不湿的时候屁屁离地最多一拳，侧身换更好，以防脊柱受伤
  4. 不要给宝宝剃光头、刮眉毛、剪睫毛、挤乳头、绑腿
  5. 不要把屎把尿
  6. 注意宝宝黄疸，多吃多拉晒太阳可降黄疸，黄疸值高于12就医

第8~14天：可以开始做产褥操

重点事项 伤口恢复后，可躺着做产褥操，帮助身体恢复
饮食推荐 可适当摄入一些补血食材，为增加奶水做准备（温补滋养）
菜：山药炒木耳、糖醋里脊、蛤蜊炖蛋、番茄胡萝卜炖牛腩
汤：丝瓜瘦肉汤、豆腐鲫鱼汤、海底椰煲鸡汤、党参猪心汤
  1. 如果血性恶露持续2周以上，量多或者为脓性有臭味或者伴有大量出血等症状，应立即就医
  2. 顺产后一周，剖腹产伤口愈合后，开始做产褥操：腹式呼吸（瘦肚子）、提肛运动（预防漏尿，子宫脱垂）、按摩腹部（消肚子）
  3. 顺产后一周，剖腹产两周，可以做凯格尔运动（改善盆底肌松弛，缓解腰背酸痛）—具体方法往后翻

第15~21天：母乳不足，学会追奶（第三周）

重点事项 产后2周进入泌乳高峰期，母乳不足的多试一些追奶方法
饮食推荐 高蛋白食物：瘦肉、牛羊肉、猪蹄、章鱼、虾、鲫鱼、豆腐
下奶的蔬菜：丝瓜、莲藕、莴笋、豌豆、茭白、山药、红枣
多吃这些水果：木瓜、橘子、樱桃、葡萄、奇异果
  1. 多亲喂，多吃多产，直到供需平衡
  2. 开始吃一些下奶汤：鲫鱼豆腐汤、乌鸡汤、通草猪蹄汤、五红汤等
  3. 每次喂奶前小口喝200ml的温水，每天要保证2000ml以上的水量
  4. 保持好心情，每天保证8小时睡眠，比什么下奶汤都有用
  5. 夜间休息好，泌乳高峰，喂奶后用吸奶器追奶20分钟，吸1-2个奶阵
  6. 宝宝15天开始每天一粒维生素D，帮助钙吸收

第22~28天：学会和宝宝早教互动（第四周）

重点事项 了解1月龄宝宝发育特点，进行互动
饮食推荐 宜吃：党参补气猪心汤、椰肉红枣鸡汤、阿胶瘦肉水
忌：韭菜、麦芽、大麦茶、薄荷、酒精、浓茶等回奶食物

宝宝发育特点：对声音有反应，双眼视线模糊，只能看到几米

爸妈可以这样做：

  1. 给宝宝看黑白卡，距离眼睛20cm，每次1-2张重复，让宝宝追视
  2. 小沙锤在耳边20cm处摇晃，从左到右，宝宝会追听，刺激听觉
  3. 大动作：喂奶1小时后练习俯卧，每次10秒，锻炼宝宝上肢力气
  4. 触觉：练习抓握手指，做抚触促进肢体感官发育

第29~35天：为二月肠胀气做准备（第五周）

重点事项 宝宝肠胀气，肚肚难受易哭闹，提前学习应对方法
饮食推荐 母乳妈妈少吃产气食物：豆制品、奶制品、根茎类、十字花科食物；含果糖、淀粉类多的食物少吃，容易产气
比如：西蓝花、卷心菜、白菜、南瓜、玉米、红薯、山药等
  1. 不要宝宝一哭就喂奶，吃零碎奶会加重肠胃负担，胀气更严重
  2. 喂奶后拍嗝，如果实在拍不出来，竖抱10分钟
  3. 二月闹的时候可以瓶喂，定点定量喂，没到奶点哭可以给安抚奶嘴
  4. 吃奶1小时后做排气操，要坚持，打屁效果好
  5. 飞机抱、真香坐姿、趴睡（大人看着）、45度温水隔衣服热敷小肚肚、游泳，都可以排气

第36~42天：产后42天检查（第六周）

重点事项 妈妈身体基本恢复，宝宝逐渐强壮，可以安排外出了
饮食推荐 早餐：灌汤包、牛肉蔬菜饼、香蕉西芹汁
中餐：杂粮板、金针肥牛卷、耗油生菜、羊肚菌脊骨汤
晚餐：燕麦饭、紫苏焖排骨、番茄炒蛋、虾滑冬瓜汤
  1. 身体基本恢复，可以带宝宝在小区附近转一转，不要去人多的地方
  2. 出月子后如果有人员变动，提前做好分工，后面不会手忙脚乱
  3. 留意身体不适，比如耻骨痛、腰痛、漏尿、腹直肌分离等，针对性进行缓解
  4. 产后42天，妈妈和宝宝一起去医院做一次全面检查，宝宝记得陪同
  5. 出月子后也要注意休息、营养补充

抓住产后恢复黄金期

1. 腹式呼吸

时间：顺产产后一周，剖腹产伤口恢复后

作用：增加腹肌弹性、瘦肚子

做法：
1. 平躺，鼻子缓缓吸气，腹部慢慢鼓起5秒
2. 嘴巴吐气，呼气时腹部慢慢收紧5秒。反复吸气-吐气

建议：每天早晚各练10分钟，出月子肚子就会平很多！

2. 按摩腹部

时间：顺产产后一周，剖腹产伤口恢复后

作用：排恶露、排气、消肚子

做法：顺时针揉腹部50-100下，用点力气

建议：泡脚时间15分钟内，出汗了及时更换衣服。

3. 提肛运动

时间：顺产产后一周，剖腹产伤口恢复后

作用：预防漏尿、子宫脱垂

做法：平躺屈膝，深吸气，同时收缩并向上提肛门10秒（尿一半被中断的感觉），再放松10秒

建议：运动前排空膀胱，坐躺站都可以，想起来就练！

抓住产后恢复黄金期

4. 凯格尔运动

时间：顺产产后一周，剖腹产两周

作用：改善盆底肌松弛，缓解腰背酸痛

做法：
1. 平躺，双腿膝盖弯曲
2. 收缩臀部肌肉，向上提肛
3. 保持盆底肌肉收缩10秒，慢慢放松十秒,同时臀部落下

建议：每天早晚各练10分钟，出月子肚子就会平很多！

5. 上肢运动

时间：产后10天

作用：瘦肩背、减少乳房下垂

做法：
1. 躺平，双腿分开与肩同宽，双臂自然放平
2. 双臂尽量向上伸直，双掌合拍
3. 将上臂缓缓举过头，沿着床面或地面伸直
4. 最后慢慢收回，双臂自然放平

建议：运动前排空膀胱，坐躺站都可以，想起来就练！
