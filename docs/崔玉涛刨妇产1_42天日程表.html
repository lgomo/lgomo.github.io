🌙产后月子

崔玉涛 · 剖腹产 1-42 天日程表

崔玉涛推荐剖腹产坐月子1-42天日程表

注意事项+饮食营养

✓新手爸妈必知道的事（建议打印）

第1天：请好好休息

类别 内容
重点事项 尽早开奶，术后2小时内让宝宝吃母乳
饮食推荐 小米粥、南瓜小米粥、白萝卜汤
  1. 剖腹产2小时内，给宝宝喂初乳，早接触、早开奶
  2. 产后6小时内平躺，6小时后枕枕头，多翻身，防止粘连
  3. 翻身技巧：可一手推着床护栏来借力，然后往对侧慢慢挪屁股，胳膊肘撑着，另一手伸过来抓护栏、翻身，注意不要压折尿管。
  4. 产后6小时左右医生会拔尿管，拔完后下床上厕所，会有刺痛感
  5. 留意是否头晕、呕吐等。如果呕吐，家属要将产妇的头偏向一侧，并及时清理口腔异物。
  6. 排气后才能喝水吃饭，以流食为主，比如米粥，稀面条，不喝牛奶，避免胀气。
  7. 回病房会挂生理盐水，打缩宫素等，宫缩比较痛，可以用双氯芬酸钠栓，自己提前买。
  8. 家属要时不时地带产妇按摩下肢，预防血栓。
  9. 当腿脚有知觉后，自己可以轻抬、弯曲、多动动

第2天：产后多翻身，下床走动

类别 内容
重点事项 新生儿喂奶按需喂养
饮食推荐 小米粥、蔬菜包、鸡蛋蔬菜面、枸杞莲子羹
  1. 产后第一周，不喝下奶汤，不吃油腻食物，避免堵奶。
  2. 剖腹产第二天用束缚带，缓解伤口拉扯疼痛感，防止内脏下垂。
  3. 新生儿喂奶先亲喂30分钟（两边各15分钟），吃不饱再喂配方奶每次20-30ml，间隔2-3小时，按需哺乳。
  4. 3-4小时换一次卫生巾，睡前用温水清洗私处，温水可加碘伏。
  5. 产后比较虚弱，怕冷，刷牙时尽量用温水。
  6. 刚下地不要逞强走太远，缓慢地在病房里走走就好。
  7. 多喝水，多去洗手间，不要怕麻烦。
  8. 下床技巧：下床前可让家属将床头慢慢摇起，摇到一定缓度，注意不要一下摇成90°，产妇侧身，将两条腿依次沿床边慢慢垂下。家属搀扶产妇缓身慢起，尽量拎着产妇的腋下避免压到刀口。下地站直瞬间，产妇可抱住家属缓一下，防止晕倒。

第3天：出现生理性胀奶

类别 内容
重点事项 开始生理性胀奶，持续一周左右，提前备好吸奶器
饮食推荐 虾皮蒸蛋羹、小米南瓜粥、什锦炒香菇、菠菜面条
  1. 生理性胀奶，让宝宝多吸吮，如果宝宝不吸，吸奶器2-3小时吸一次。
  2. 且勿用热水热敷乳房，可以用包菜、土豆片、冷敷消肿。
  3. 副乳肿胀，可一边喂奶一边轻揉，力度轻
  4. 汗体多，及时更换衣服，睡衣一定选用乳量的
  5. 多喝温水，吃些蔬菜和蒸熟的水果，便秘严重可借助开塞露。
  6. 不要过早抱孩子，身体未恢复，多躺多睡。

第4天：多下地走动

类别 内容
重点事项 不要久站、弯腰，一定要有家人陪同，包括去洗手间都要陪着去
饮食推荐 黑芝麻糊、清蒸鲈鱼、肉片炒蘑菇、红枣银耳汤
  1. 可以洗澡，但是都要用温水，千万不能用冷水，刷牙要用软毛牙刷。
  2. 继续观察恶露情况，这个时候的恶露还是比较多，颜色是深红色注意坚持用温水清洗保持干净卫生。
  3. 伤口2-3天换一次绷带
  4. 克制住，不要大笑和用力咳嗽，会扯到伤口！
  5. 坚持每次喂奶前、喂奶后都要小口小口喝温水，有助于提升奶量

第5天：准备出院回家啦

类别 内容
重点事项 宝宝提前办理出院手续
饮食推荐 银耳羹、杂粮馒头、菠菜猪肝汤、桂圆红枣汤
  1. 提前问好医院周几办出生证明，有些医院一周只有一两天办这个
  2. 剖腹产回家后可洗头（躺着洗）、擦澡，等一周左右伤口愈合再淋浴
  3. 不要捂月子，可开空调，24-26°C比较舒适，房间每天通风2次
  4. 剖腹产妈妈可以正常饮食了，多吃维C和优质蛋白，有利于伤口恢复
  5. 哺乳期每天三餐两点，哺乳耗气血，饮食要均衡。
  6. 出院当天，绑着收腹带，伤口不那么痛了，可以自己行走

第6天：分工照顾妈妈和宝宝

类别 内容
重点事项 宝爸要做好家人的分工，宝宝回家要多休息
饮食推荐 奶黄包、虾仁玉米粥、清炒时蔬、南瓜软饭、花生排骨汤
  1. 宝宝洗澡后，用碘伏给脐带消毒，保持干燥，一般两周左右脱落
  2. 宝妈不碰凉水、不弯腰、不提重物，除了喂奶少抱宝宝
  3. 血性恶露减少，变成淡红色的浆性恶露，量减少，持续10天左右
  4. 保持心情愉悦和良好睡眠，预防产后抑郁
  5. 此时宝宝奶量大约是60ml/次，一天喂养8次（母乳宝宝按需喂养）
  6. 记得给宝宝办理户口本、新生儿保险
  7. 正确使用收腹带，缓解刀口被牵拉的疼痛感
  8. 准备高腰内裤，穿宽松的衣服，防摩擦
  9. 多吃维生素C和高蛋白的食物，禁辛辣和发物，容易疤痕增生

第7天：适应宝宝的作息时间

类别 内容
重点事项 宝宝睡觉的时候宝妈要休息，闭目养神也可以
饮食推荐 水煮蛋、蔬菜粥、芹菜肉丝汤、青菜炒鸡心、栗子饭
  1. 产后容易贫血缺钙，继续补铁、补钙，有利于身体恢复
  2. 不要长时间躺着看手机，尤其是半夜，视力下降真的很快
  3. 母乳妈妈保证8-10h睡眠，每天喝水2000ml以上，有助于乳汁分泌
  4. 不要攒奶，多吃多产奶。半夜容易堵奶，宝宝吃不完一定要吸出来
  5. 喂奶前可温水热敷，促进乳汁分泌，喂奶后冷敷，缓解肿胀
  6. 不要一直躺着，可适当室内走动，促进血液循环，注意不要做家务

第8天：了解宝宝护理误区

类别 内容
重点事项 学习新生儿护理知识，科学照顾宝宝
饮食推荐 小米海参粥、鳕鱼豆腐汤、豌豆饭、木瓜银耳羹
  1. 宝宝比大人多半件，摸颈部温热，手脚微凉但不冰，就是穿衣合适
  2. 纯母乳喂养不需要额外喝水，奶粉宝宝两餐之间喂10ml左右水
  3. 换尿不湿的时候屁股离地最多一拳，侧身换更好，以防脊柱受伤
  4. 不要给宝宝剃光头、刮眉毛、剪睫毛、挤乳头、绑腿、不要把屎把尿
  5. 注意宝宝黄疸，多吃多拉晒太阳可降黄疸，晒太阳避免阳光直射

第9天：可以开始做产褥操

类别 内容
重点事项 伤口恢复后，可躺着做产褥操
饮食推荐 番茄鲜虾豆腐、红豆饭、菜猪肝汤、牛肉炒青菜、肉包子
  1. 如果血性恶露持续2周以上，量多
    或者为脓性有臭味或者伴有大量出血等症状，应立即就医
  2. 剖腹产伤口愈合后，开始做产褥操：腹式呼吸（瘦肚子）提肛运动（预防漏尿，子宫脱垂）、
    按摩腹部（消肚子）
  3. 剖腹产两周，可以做凯格尔运动（改善盆底肌松弛缓解腰背酸痛）

第10-12天：重视宝宝的心理需求

类别 内容
重点事项 宝宝只是还不会说出他的需求，不是没有需求
饮食推荐 煮鸡蛋、竹笋莲子鸡、清炒娃娃菜、黄豆炖猪蹄、黄瓜汁
  1. 多与宝宝对视，丝给他看色彩鲜艳、会转动的玩具
  2. 多与宝宝说话，让宝宝有安全感
  3. 多给宝宝温柔抚摸，促进宝宝的发育
  4. 多逗宝宝笑，宝宝一般是在出生10天左右会被逗笑

第13-14天：母乳不足，学会追奶

类别 内容
重点事项 进入泌乳高峰期，母乳不多的多试一些追奶方法
饮食推荐 煮玉米、炒鸡蛋、腰果虾仁、花生排骨粥、冰糖雪梨汤
  1. 多亲喂，多吃多产，直到供需平衡
    开始吃一些下奶汤：鲫鱼豆腐汤、乌鸡汤、通草猪蹄汤、五红汤等
  2. 下奶汤要荤素搭配，不要只喝肉汤，以免堵奶
  3. 每次喂奶前小口喝200ml的温水，每天要保证2000ml以上的水量
  4. 保持好心情，每天保证10小时睡眠，养气血特别好好
  5. 哺乳或者喂奶前进行热敷，水温40-45度即可，避开乳头乳晕
  6. 夜间休息好，泌乳高峰，喂奶后半小时喝杯热水，可用吸奶器吸
  7. 晚上热水冲乳房5-10分钟，冲后背5-10分钟，促进血液循环，产奶多
  8. 喂奶时可轻挤压腋下和乳房下延，更有利于乳房排空
  9. 宝宝15天开始每天一粒维生素D，帮助钙吸收

第15-18天：快速恢复期

类别 内容
重点事项 身体状态好多了，基本适应每天跟哄宝宝的生活作息了，可以开始调整宝宝睡眠了
饮食推荐 鸡蛋饼、红烧土豆鸡块、鲫鱼豆腐汤、莴笋炒虾仁
  1. 可以做一些轻微的家务，如：整理衣物，有助于恢复
  2. 让宝宝区分昼夜，最有效的方法就是：让宝宝明白
    白天是有趣的，白天有人陪他玩。晚上是安静的，没有人陪玩
  3. 建立相对固定的睡眠时间和哄睡方式
  4. 从第15天开始，每天给宝宝补充400国际单位的维D

第19-23天：学会和宝宝早教互动

类别 内容
重点事项 了解1月龄宝宝发育特点，进行互动
饮食推荐 党参补气猪心汤、桂圆红枣乌鸡汤、阿胶瘦肉水
  1. 给宝宝看黑白卡，距离眼睛20cm，每次1-2张重复，让宝宝追视
  2. 小沙锤在耳边20cm处摇晃，从左到右，宝宝会追听，刺激听觉
  3. 大动作：喂奶1小时后练习俯卧，每次10秒，锻炼宝宝上肢力气
  4. 练习抓握手指，做抚触促进肢体感官发育

第24-28天：为二月肠胀气做准备

类别 内容
重点事项 宝宝肠胀气，肚肚难受易哭闹，提前学习应对方法
饮食推荐 鱼肉排骨汤、黑米饭、茭白炒牛肉、鸡蛋米酒汤、木瓜炖牛奶
  1. 不要宝宝一哭就喂奶，吃零碎奶会加重肠胃负担，胀气更严重
  2. 喂奶后拍嗝，如果实在拍不出来，要竖抱10分钟再放床上
  3. 二月闹的时候可以瓶喂，定点定量喂，没到奶点哭可以给安抚奶嘴
  4. 吃奶1小时后做排气操，要坚持，放屁效果好
  5. 飞机抱、真香坐姿、趴睡（大人看着）、45度温水隔衣服热敷小肚肚、游泳都可以排气

第29-34天：美丽妈妈行动

类别 内容
重点事项 月子就要坐完了，开始关注自己的"美丽"大事吧
饮食推荐 白灼苏蓝、板栗烧鸡、蘑菇青菜、清蒸鲈鱼、蒸紫薯
  1. 刷牙：选择合适的牙刷，早晚用温水漱口
  2. 头发：用指腹按摩头皮，清洗后适当用护发素
  3. 皮肤：补充睡眠，多吃含维C、维E的蔬果
  4. 脸部：日常脸部清洁和保湿，每周2-3次的脸部按摩
  5. 身材：选择轻度的有氧运动，必要时做产后康复
  6. 恶露：一般4-6周排完，如未排干净，及时就医

第35-41天：宝宝的首次外出

类别 内容
重点事项 妈妈身体基本恢复，宝宝逐渐强壮，可以安排外出了
饮食推荐 菠菜鸡蛋面、山药莲藕排骨汤、清炒时蔬、通草鲫鱼汤
  1. 身体基本恢复，可以带宝宝在小区附近转一转，不要去人多的地方
  2. 出月子后如果月嫂要下户，提前做好分工，后面不会手忙脚乱
  3. 留意身体不适，比如耻骨痛、腰痛、漏尿、腹直肌分离等，针对性进行缓解
  4. 产后42天，妈妈和宝宝一起去医院做一次全面检查，宝宝记得陪同
  5. 出月子后也要注意休息、营养补充

第42天：产后42天检查

类别 内容
重点事项 分娩后的第一次全面体检，包括新妈妈的和宝宝的
饮食推荐 奶黄包、炒竹笋、清蒸排骨、冬瓜肉丸汤、绿豆莲子汤
  1. 预约体检医院备齐体检资料（产检报告、出院小结等）
  2. 除了宝宝做检查，妈妈也要做体检建议老公陪同前去
  3. 宝宝体检项目，包括：头尾/身胸围/体重测量、婴儿智力发育评价和喂养指导
  4. 妈妈的检查，包括：询问妊娠、分娩和坐月子的情况，检查产后恢复状况
